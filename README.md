# Карточка товара «Ананасовый улун»

Верхняя часть карточки товара для тестового задания Teaboom.ru.

## Запуск

Откройте `index.html` в браузере. Сборка и сервер не нужны.

## Поведение

- Переключение фасовки меняет цену, старую цену, артикул и выбранное состояние.
- У кнопки «В корзину» есть обычное состояние и состояние при наведении. Корзина не подключена.
